# Auvraya

**Working name:** Auvraya  
**Tagline:** Ancient wisdom. Everyday balance.  
**Status:** Early planning — brand name and tagline are provisional.

Auvraya is an Android-first, bilingual (English/Hindi) Ayurveda-inspired wellness and daily-lifestyle app. It aims to offer practical, personalized routines and seasonal guidance with transparent sources and careful safety boundaries.

## Project principles
- Treat wellness content as educational guidance, not diagnosis or a substitute for qualified care.
- Keep changeable content, translations, assessment configuration, recommendation rules, and notification copy backend/CMS-managed.
- Keep secrets out of source control.
- Build in small, reviewed phases and test every meaningful change.
- Do not claim an assessment is clinically validated unless appropriate evidence supports that claim.

## Planned areas
- Flutter mobile app
- Backend, authentication, database and content APIs
- Admin CMS for reviewed, versioned English/Hindi content
- Automated checks and release documentation
