# Release Readiness Checklist

## Product
- [ ] MVP scope and acceptance criteria met.
- [ ] English and Hindi reviewed.
- [ ] Wellness content approved by qualified reviewer and source/rights checks recorded.
- [ ] Uncertain/error/offline states reviewed.
- [ ] Privacy notice and terms reviewed by appropriate professionals.

## Engineering
- [ ] Formatting, analysis, tests, and release build completed.
- [ ] No known unresolved critical/high-risk defects.
- [ ] Secrets and dependency checks completed.
- [ ] Database migrations and rollback/recovery plan reviewed.
- [ ] Monitoring, crash reporting, and support process configured appropriately.
- [ ] Account/data deletion tested.

## Release
- [ ] Store listing, screenshots, age/content declarations, and permissions reviewed.
- [ ] Applicable health-app and billing policies reviewed.
- [ ] Staging smoke test completed.
- [ ] Release owner and rollback procedure identified.
- [ ] Explicit approval obtained before production deployment.
