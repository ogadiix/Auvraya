# Frontend Rules

- Inspect existing framework and conventions before changes.
- Keep UI, domain logic, and data access separated.
- Support English and Hindi throughout.
- Handle loading, empty, error, offline, stale, and uncertain states.
- Keep mutable copy/content backend-managed with versioned schemas.
- Use accessible components, scalable text, and reduced-motion/lightweight fallbacks.
- Never embed provider secrets in client code.
